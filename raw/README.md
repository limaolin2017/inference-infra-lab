# raw/ — Source documents (read-only)

Layer 1 of the wiki. See [CLAUDE.md](../CLAUDE.md).

- Put sources here **as they are**: paper PDFs or notes, Handbook page excerpts, pinned vLLM source links, Q&A pasted from study outside the project chat.
- **Never edit a file after adding it.** Corrections go into the wiki pages.
- Name files `YYYY-MM-DD-short-name.md` (or the original file name for PDFs).
- Images go in `raw/assets/`.
- After adding a file, run the **Ingest** workflow: summarize, update concept pages, add to [index.md](../index.md), append to [log.md](../log.md).
