- **`allocate_slots()` block count:** new blocks = `ceil(total_tokens / block_size) − blocks_already_held` ([source, assistant-shown](https://github.com/vllm-project/vllm/blob/c2320e37f14420a1157967362b56c899a726d84d/vllm/v1/core/single_type_kv_cache_manager.py#L405-L411)). Initial confusion ("does decode need a block?") cleared after a picture. **L2 practice (guided); not a pass.**
- **Block life cycle (concept):** `ref_cnt` = how many requests use a block; a request leaving gives −1; only at 0 does the block go back to the free queue. A free cached block keeps its old KV: a same-prefix request can reuse it (cache hit), or someone needing an empty block overwrites it (evict). So a preempted request recomputes unless its old blocks survive. **L1–L2 practice (guided); not a pass.** Code check for this stage still pending.
