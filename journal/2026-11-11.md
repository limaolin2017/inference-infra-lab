## New — BlockPool block life cycle (L1–L2 practice, guided)

- **Big picture shown first** at learner's request: Scheduler (mostly learned) → **KV Cache Manager / BlockPool (today)** → Model Runner (next). `KVCacheManager` = front desk, `BlockPool` = warehouse.
- **Four concepts:** block, `ref_cnt`, free queue, hash. K/V stays inside a freed block until it is taken. See [concept note](../concepts/blockpool-block-life-cycle.md).
- **Three actions:** `get_new_blocks()` (front, 0 → 1), `touch()` (+1, remove from any position), `free_blocks()` (−1; at 0: no hash → front, hash → end).
