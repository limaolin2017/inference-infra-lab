## New

- **Memory-bound decode** — each step reads all weights + each request's KV cache from HBM to the compute cores; cores mostly wait in small-batch decode. **L1 practice (guided); not a pass.** See [concept note](../concepts/memory-bound-and-batching.md).
- **Batching** — weights read once and shared; KV cache per request. **L1–L2 practice (guided).**
- **Turning point** (memory-bound → compute-bound) and **throughput vs TPOT**; choosing batch size for chat vs offline jobs. **L2 practice (guided).**
