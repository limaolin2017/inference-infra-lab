Why a lookahead hash can avoid an extra CPU KV load

Each blue box is one token. A block contains four tokens: A, B, C, D. The next token is E. Watch the last block in the left card.

Old: hash only the block

H(context, ABCD)
ABCDE

The key does not say whether E or F comes next. The last EAGLE draft unit may be excluded from the cache hit.

CPU cache → GPU (possible reload)

New: include the next token

H(context, ABCD, E)
ABCDE

The hash also identifies E. If context and E match, a compatible connector can keep the safe GPU cache hit.

Reuse GPU cache (when supported)
1. Find local prefix2. Old boundary: drop3. CPU may reload4. New key: safe reuse
Important: If F follows ABCD instead of E, the lookahead hash changes. Do not reuse the wrong EAGLE draft KV. This animation is an illustration, not a performance trace or a claim that all CPU loads disappear.
